# Registration Wizard

A modern multi-step onboarding form built using React and Vite. This project simulates a SaaS-style registration flow with persistent state management, real-time validation, and a polished onboarding UI.

## Features

### Multi-Step Registration Flow
- Welcome Screen
- Personal Information Step
- Account Details Step
- Review & Submit Step
- Success Confirmation Screen

### State Management
- Centralized parent state using React `useState`
- Persistent form data across navigation
- Conditional rendering for step transitions

### Validation System
- Real-time email validation using Regex
- Password minimum length validation
- Confirm password matching validation
- Disabled Next button until valid inputs are entered

### UI/UX Features
- Dynamic progress bar
- Show/Hide password toggle
- Responsive layout
- Modern mesh-gradient background
- Card-based onboarding interface
